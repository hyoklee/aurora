The MultiSenseGolf dataset (Scientific Data 2026; the paper text is paper.txt in this
directory; Harvard Dataverse doi:10.7910/DVN/LCCLLW) has already been ingested into a
running clio-core runtime by the OMNI file golf_omni.yaml in this directory (the CAE
dataverse:// source). Do NOT download the dataset: read it from clio-core.

How to read it: in a shell, run `source ./clio_env.sh` and use the Python at
/tmp/claude-36126/-home-hyoklee-aurora/7e1b65af-7054-4a75-8def-00dce7042087/scratchpad/venv/bin/python (numpy, pandas, scipy, scikit-learn, h5py are installed).
`import cte_golf as cg` (cte_golf.py is in this directory; read its docstring):
cg.manifest() lists every ingested object and its tag, cg.read_array(tag) returns a
dataset as a numpy array, cg.read_csv(tag) returns a CSV (Documentation.zip/*.csv hold
participant metadata and per-swing annotations).

The clio-core runtime holding the data is already running: do not start, stop or
restart any clio runtime or server, and do not read the dataset from anywhere else.
If you cannot connect, stop and report the error.
